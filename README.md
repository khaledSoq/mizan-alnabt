# ميزان النبط

وزن الشعر النبطي من غير تشكيل.

الصق صدراً أو عجزاً أو بيتاً. البرنامج لا يخمن سكوناً واحداً: يولّد تقطيعات محتملة، يقيسها على قوالب البحور، ويأخذ الأعلى مطابقة. اضغط الحرف لقلب المتحرك (1) والساكن (0).

القياس على **النطق النجدي** لا على الرسم: «الله» سببان لا وتد، وال الشمسية تُدغم.

## التشغيل

لا يعتمد المحرك إلا على مكتبة بايثون القياسية.

```bash
# وزن شطر
python3 app.py "يا ما حلا بعد العشا شرب الفنجال" --meter mashub

# اكتشاف البحر تلقائياً
python3 app.py "نحمد الله جت على ما تمنى"

# بيت صدر وعجز (افصل بنجمة أو سطر)
python3 app.py "نحمد الله جت على ما تمنى *** من ولي العرش جزل الوهايب" --meter arda

# اختبارات
python3 -m unittest tests/test_engine.py -v

# واجهة JSON
python3 app.py --serve --port 8090
```

### JSON API

```
GET  /api/meters
GET  /api/weigh?text=...&meter=auto
POST /api/weigh   {"text":"...","meter":"mashub","locks":[{}]}
```

`locks` اختيارية: قاموس رقم الحرف → `1` أو `0` لتثبيت التقطيع يدوياً.

## البحور

| المعرّف | الاسم | تفعيل |
|---|---|---|
| `mashub` | المسحوب | مستفعلن مستفعلن فاعلاتن |
| `hilali` | الهلالي | مستفعلن مستفعلن مستفعلن فاعلن |
| `sakhri` | الصخري | مفاعيلن مفاعيلن فعولن |
| `hajini` | الهجيني | فعولن فعولن فعولن فعولن |
| `hida` | الحداء | مستفعلن فاعلن مستفعلن فاعلن |
| `arda` | العرضة | فاعلاتن فاعلاتن فاعلاتن فاعلن |

الزِحافات الشائعة داخلة في القوالب (خبن المستفعلن، قبض الفعولن، …).

## كيف يعمل

1. **تطبيع** الشطر وإسقاط التشكيل إن وُجد.
2. **توليد مرشحين** لتسكين الحروف الواو/الياء/الألف حسب قواعد النبط، لا تخمين واحد.
3. **مطابقة** سلسلة 1/0 على قوالب التفاعيل (سبب `10` = لا، وتد `110` = نعم).
4. **اختيار** أعلى درجة. دون `0.90` يظهر الكسر وموضع الصندوق المكسور.

المحرّك مكتوب مرتين: بايثون في [`engine/`](engine/) وجافاسكربت/تايبسكرپت في [`src/lib/arud/`](src/lib/arud/) لنفس المنطق داخل الواجهة.

## الواجهة

- [`src/routes/index.tsx`](src/routes/index.tsx) — اللصق، اختيار البحر، الأمثلة
- [`src/components/hemistich-view.tsx`](src/components/hemistich-view.tsx) — الحروف القابلة للقلب وصناديق لا/نعم
