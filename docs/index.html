ميزان النبط

الصق الشطر ثم اضغط «زِن البيت». البرنامج يولّد تقطيعات ويقارنها بالبحور. اضغط الحرف: متحرك ← ساكن ← شدة.

1 متحرك · 0 ساكن · لا = 10 · نعم = 110. الاسم المشدد (حمّاد): اضغط الميم حتى تظهر الشدة.
